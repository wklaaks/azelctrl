Critical Context
IRAM Architecture & Usage: IRAM (Instruction RAM) is 32KB dedicated memory for time-critical code. ESP8266 shares flash bus between CPU and WiFi radio. During WiFi DMA, flash is locked; code must run from IRAM. Consumers: WiFi radio ISRs (~10KB), TCP/IP stack ISRs (~5KB), Core runtime (~4KB), I2C handlers (~2KB), Flash cache management (~2KB), Math helpers (~1KB), SDK internals (~4KB). Total ~28KB/32KB (93%). Headroom ~4KB. DNSServer uses zero IRAM (all flash). New code must avoid ICACHE_RAM_ATTR. HTML moved to PROGMEM to save heap, not IRAM.

EEPROM Layout & Credential Persistence: EEPROM_SIZE = 67. Bytes 0-32: SSID (max 32 chars). Bytes 33-65: Password (max 32 chars). Byte 66: Magic 0xAA. EEPROM.begin(67). Credentials loaded on boot; invalid magic or zero SSID length triggers captive portal.

Button & I2C Pin Mapping: D8 (GPIO15) = Btn1 (active HIGH, menu cycle/select). D5 (GPIO14) = Btn2 (active LOW, confirm/start movement). I2C: D6 (SDA), D7 (SCL). OLED uses SSD1306.
